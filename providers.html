Providers & genuine outcomes

HEXBAZAAR can request infrastructure observations from public HTTPS providers. A live observation is source metadata, not proof that a hostname is presently active or that a person owns it.

DNS

Public A/AAAA and DNS context, including sanitized policy summaries. DNS data can change or be cached.

RIPEstat

Network context and public Internet routing information. Network association does not prove ownership.

CertSpotter

Public certificate-linked DNS names and dates. Certificate entries do not prove a service is currently reachable.

urlscan

Publicly indexed hostname observations. Results are limited by indexing and service availability.

Honest feedback: HTTP 429 = throttled; HTTP 502/503 = provider unavailable; timeout = connection failed; zero accepted observations = no usable findings. The live engine prints statuses instead of manufacturing results.
