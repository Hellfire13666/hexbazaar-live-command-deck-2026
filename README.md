**Separate companion launch page for the genuine installed HEXBAZAAR Savage Intel Shop v0.1.2-rc1.** This package does **not** include, fork, or overwrite that research engine. Its commands call the real installed Python 3 public-source CLI. The main Start, Easy, Medium, and Savage recipes use `domain --live`; **synthetic demos are not on the launch page**.

## What it really runs

- `start`: actual public DNS query against `example.com`.
- `easy`: DNS only against `facebook.com`.
- `medium`: DNS + RIPEstat on `example.com`.
- `savage`: four public-source providers on `facebook.com`.
- `check` or `shop`: *real local tool detection*, not proof of a live response.
- `guide`: offline HTML page with real copy buttons.

The installed original engine must exist at one of the two recognized v0.1.2-rc1 versioned folders. If not, the deck prints a truthful missing-engine error. Real providers may return 0 results, HTTP 429, timeouts or partial responses. Findings are public network metadata, not proof of identity or wrongdoing. Nothing saved by default.

## 🐧 One-square Debian install

Download `HEXBZ-LIVE-COMMAND-DECK-v0.1.0.zip` and its `.sha256` checksum file into `~/Downloads`, then paste:

```bash
cd "$HOME/Downloads" &&
sha256sum -c HEXBZ-LIVE-COMMAND-DECK-v0.1.0.sha256 &&
unzip -tq HEXBZ-LIVE-COMMAND-DECK-v0.1.0.zip &&
mkdir -p "$HOME/PhantomLabsLaunchers" &&
test ! -e "$HOME/PhantomLabsLaunchers/HEXBZ-LIVE-COMMAND-DECK-v0_1_0" &&
test ! -L "$HOME/PhantomLabsLaunchers/HEXBZ-LIVE-COMMAND-DECK-v0_1_0" &&
unzip -q HEXBZ-LIVE-COMMAND-DECK-v0.1.0.zip -d "$HOME/PhantomLabsLaunchers" &&
python3 -B "$HOME/PhantomLabsLaunchers/HEXBZ-LIVE-COMMAND-DECK-v0_1_0/scripts/verify_package.py" &&
bash "$HOME/PhantomLabsLaunchers/HEXBZ-LIVE-COMMAND-DECK-v0_1_0/INSTALL_DESKTOP_AND_ALIAS.sh" &&
bash "$HOME/PhantomLabsLaunchers/HEXBZ-LIVE-COMMAND-DECK-v0_1_0/OPEN_GUIDE.sh"
```

**Separate Start anytime:**

```bash
"$HOME/.local/bin/hexbazaar-live-deck" start
```

If you have slow internet, `easy` (one public DNS provider) is the smallest live request. `savage` can be slower or partially rate limited.
